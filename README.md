# Web professional · Francesc Xavier Sala Cervós

Web d'una sola pàgina en HTML, CSS i JavaScript, sense dependències, publicada amb GitHub Pages a https://xaviersalacervos.github.io/

## Estructura
- `index.html`: tota la pàgina (en català)
- `css/style.css`: estils (paleta blau petroli #1E3A45, terracota #A4471F, paper #FAF8F4)
- `js/main.js`: menú mòbil i secció activa (la web funciona igual sense JS)
- `assets/`: foto, tipografies autoallotjades (Source Serif 4 i Source Sans 3, llicència SIL OFL), favicon i imatge per compartir
- `cv/`: CV en PDF sense telèfon, adreça ni números de col·legiat
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`

## Fer canvis
Edita els fitxers i puja'ls a la branca `main`. GitHub Pages republica la web en un o dos minuts.

## Pendent opcional
- LinkedIn: activa la línia comentada de la secció Contacte d'`index.html`.

## Afegir castellà o anglès
Crea `es/index.html` i `en/index.html` copiant `index.html`. Canvia `lang`, les rutes (`../css/style.css`, etc.) i activa les línies `hreflang` comentades a la capçalera.

## Privacitat
El repositori és públic: no hi pugis mai els CV en Word, que porten telèfon i números de col·legiat.
